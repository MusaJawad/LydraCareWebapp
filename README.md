# LYDRA Care Multipage PHP Site

This project is a static multipage PHP site built from the original `lydra-care-dashboard (1).html` design.

## Files included
- `index.php` — Dashboard homepage
- `activity.php` — Activity Log
- `medications.php` — Medications
- `alerts.php` — Alerts
- `family.php` — Family Circle
- `messages.php` — Voice Messages
- `health.php` — Health Insights
- `settings.php` — Settings
- `header.php` — Shared header/sidebar/topbar layout
- `footer.php` — Modals, toast and script include
- `assets/style.css` — Shared styles
- `assets/script.js` — Shared interactions

## How to upload to Hostinger
1. Upload all files and folders to your Hostinger `public_html` directory.
2. Make sure `index.php` is present in the root of the upload folder.
3. Open the site URL in your browser. The PHP pages should work automatically.

## Notes
- This is not a WordPress theme. It is a standalone PHP multipage site.
- You can still upload it alongside a WordPress site in a subfolder if desired.
- If you want a WordPress-compatible theme instead, I can convert this into a WordPress template.
